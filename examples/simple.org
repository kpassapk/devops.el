#+SERVER: server1 (source)
#+SERVER: server2 (target)
#+TITLE: Run commands on multiple servers

Instructions
1. Place cursor in code block
2. Run =devops-set-header-args-from-tag=
3. You should see header-args set as follows

#+begin_example
:PROPERTIES:
:header-args: :dir app@server1:
:END:
#+end_example

Try the same for =target=

#+begin_example
:PROPERTIES:
:header-args: :dir app@server2:
:END:
#+end_example

* List source                                                        :source:

#+begin_src sh
  ls
#+end_src

* List target                                                        :target:

#+begin_src sh
  ls
#+end_src

* What's happening?

=devops.el= parses the =SERVER= properties at the top of the file.

#+begin_example
#+SERVER: server1 (source)
#+end_example

It constructs the header arguments
