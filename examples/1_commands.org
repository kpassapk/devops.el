#+PROPERTY: header-args:sh :results output
#+TARGET: server1 /ssh:example1.com:
#+TARGET: server2 /ssh:example2.com:
#+TITLE: Running server commands

=devops.el= helps you run commands on one or more named targets by declaring them at the the top of the file.

#+begin_example
#+TARGET: server1 /ssh:example1.com:
#+TARGET: server2 /ssh:example2.com:
#+end_example

Normally, org-babel runs commands on servers whenever the =:dir= header argument
is set to a remote location. To run =ls= on =example1.com=, we could write

#+begin_example
#+begin_src sh :dir /ssh:user@example1.com:
ls
#+end_src
#+end_example

With =devops.el=, we can run the same command by adding a tag to a parent heading:

#+begin_example
,** some-heading                                                     :server1:

,#+begin_src
,  ls
,#+end_src
#+end_example

* Try it

Instructions:
1. Modify the server blocks at the top of file
2. Run =devops-set-header-args-from-tag=
3. You should see header-args set as follows

Try the same for =target=

#+begin_src sh :results output

#+end_src

** List target                                                      :server2:

#+begin_src sh :results output
ls
#+end_src

** List both :server1:server2:

* Linking to a target

A =target:= link points at a path under a target, so a link survives the
target moving to a new host.  =C-c C-o= opens it: a file through TRAMP,
or a browser page when the target is a URL.

#+begin_example
#+TARGET: grafana https://grafana.example.com

[[target:server1:/etc/nginx/nginx.conf][nginx config on server1]]
[[target:grafana:d/node-exporter][node dashboard]]
#+end_example

[[target:server1:/etc/nginx/nginx.conf][nginx config on server1]]

=C-c C-l target: RET= picks a tag and asks for the path.
